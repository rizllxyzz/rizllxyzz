## 🚀 Featured Project

### [Presensi School - Smart Attendance System](https://github.com/rizllxyzz/Attendance-Agent)

Smart attendance with **Face ID**, **GPS anti-spoofing**, and **AI agent** (SmartJournal AI).

- ✅ Face ID enrollment & verification (descriptors only, no photos stored)
- ✅ GPS radius verification with anti-spoofing heuristics
- ✅ AI chatbot for attendance queries (Zetaris + Nightshift)
- ✅ Real-time recap & history per student
- ✅ Izin/Sakit request flow with approval
- ✅ Admin panel: settings, users, classes, reports, AI provider
- ✅ Docker full stack (MySQL + PHP + Agent)
- ✅ Python agent with Zetaris + Scout Intent (Meterless) + Nightshift
